# Research Methodology

## 1. 연구 배경

LMS 사용이 일반화되면서 학생들이 온라인 학습 과정에서 남기는 다양한 활동 로그를 활용하여 학업 특성을 파악하고 맞춤형 교육 정보를 제공하는 것을 연구의 출발점으로 삼았습니다.

## 2. 연구 목적

- IT 관련 학과 학생들의 전반적인 학업 패턴과 기본 통계 분석
- 학생 수강 로그를 기반으로 유사한 학습 패턴을 가진 학생 그룹화
- 각 그룹의 약점을 보완할 수 있는 맞춤형 교과 커리큘럼 제안

## 3. 연구 데이터

- 분석 기간: 2020년 3월 ~ 2023년 12월
- 원천 데이터: 약 2,000명의 IT 관련 학과 학생 LMS 데이터
- 활용 데이터: LMS 활동 정보, 개설 강의 정보, 학생 학점, 강의계획서
- 정제 후 분석 데이터: 1,106명

## 4. 특성 설계

### 학습자 상호작용

1. Learner–Instructor
2. Learner–Learner
3. Learner–Content
4. Course Activities

### 강의 방식

강의계획서에 정의된 강의 방식을 다음 4개 유형으로 그룹화했습니다.

- Lecture
- Practice / Experiment
- Flipped / Blended Learning
- Problem / Project Based Learning

## 5. 데이터 정제

데이터 표준화 및 정규화 이후 학업 특성 파악이 어려운 데이터를 제거하고 학생별 속성 데이터와 연도별 성적 변동 데이터를 구성했습니다.
